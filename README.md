# N100 Financial Intelligence

A FinTech financial intelligence dashboard for NIFTY 100 companies.

## Project Overview

This project provides financial analysis, screening, peer comparison, trend analysis, sector analysis, capital allocation analysis, annual-report access and valuation insights for NIFTY 100 companies.

## Dashboard

The application is built using Streamlit and uses a SQLite database.

### Run the Dashboard

From the project root:

```powershell
streamlit run app.py
